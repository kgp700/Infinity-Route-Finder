# 우회길 — 정체 구간 피해서 네이버 지도로 안내받기

서버 없이 폰 브라우저에서만 돌아가는 웹앱(PWA)입니다.

- 지도와 실시간 정체 색상: 카카오맵 JavaScript SDK
- 회피 경로 계산: OpenRouteService(OSM 기반, 무료 키)
- 경로의 실시간 정체 색상과 실제 소요시간: TMAP 경로 API (선택, 무료 키)
- 실제 안내: 네이버 지도 앱 (`nmap://` 링크로 경유지 전달)

파일을 무료 정적 호스팅(GitHub Pages)에 올려두기만 하면 됩니다. 돌려둘 서버는 없습니다.

## 1. GitHub Pages에 올리기 (10분)

1. github.com에서 새 저장소를 만듭니다 (예: `detour`, Public).
2. 이 폴더의 파일 6개(`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`)를 그대로 업로드합니다. (저장소 화면 → Add file → Upload files)
3. Settings → Pages → Branch를 `main` / `(root)`로 두고 Save.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/detour/` 주소가 생깁니다.

## 2. 카카오 JavaScript 키 (무료)

1. developers.kakao.com 로그인 → 상단 **앱** 메뉴에서 앱 생성.
2. 앱 설정 → 플랫폼 키 → JavaScript 키 → **JavaScript SDK 도메인**에 `https://<깃허브아이디>.github.io` 등록 (경로 없이).
3. 같은 화면에서 **JavaScript 키**를 복사합니다.
4. 왼쪽 메뉴 제품 설정 → **카카오맵** 사용 설정을 켭니다. 사업자 정보 등록과 카카오 로그인 리다이렉트 URI는 필요 없습니다.

## 3. OpenRouteService 키 (무료)

1. https://account.heigit.org/signup 에서 가입 → https://account.heigit.org 대시보드에서 무료(Standard) 키 발급.
2. 경로 한 번 찾을 때 약 4번 호출하므로 하루 수백 번 검색까지 충분합니다.

## 3-1. TMAP 앱 키 (선택이지만 추천)

넣으면 경로선이 원활/서행/지체/정체 색으로 표시되고, 빨간 정체 구간을 눌러서 바로 회피할 수 있습니다. 우회 경로 시간도 실시간 교통 기준으로 비교합니다.

1. openapi.sk.com 가입 → 앱 만들기 → TMAP API 사용 신청.
2. 앱 키를 복사해 앱 설정 화면의 "TMAP 앱 키" 칸에 넣습니다.
3. 무료 플랜은 하루 1,000건이고, 넘으면 자동 차단됩니다(과금 없음). 경로 한 번 찾을 때 약 4건 씁니다.

## 4. 폰에서 설치

1. 폰 브라우저로 1번 주소를 엽니다.
2. 처음 화면에 두 키를 붙여넣고 저장합니다. 키는 그 폰에만 저장됩니다.
3. 홈 화면에 추가합니다.
   - 아이폰 Safari: 공유 버튼 → 홈 화면에 추가
   - 안드로이드 Chrome: 메뉴 → 앱 설치(홈 화면에 추가)
4. 위치 권한을 허용합니다.

## 사용법

두 가지 상황을 위한 앱입니다.

- **미리 구상**: 집에서 목적지를 검색하고, 평소 잘 막히는 구간(예: 서용인IC~양지IC)을 찍어 우회 방법을 미리 봅니다.
- **가는 도중**: 휴게소 등에서 앱을 열면 현재 위치가 출발지가 됩니다. 앞에 막히는 구간을 찍으면 거기서부터 우회 방법을 찾습니다.

1. 목적지를 검색합니다. 출발지는 현재 위치가 기본입니다.
2. 피할 구간을 고릅니다. 두 가지 방법이 있습니다.
   - **정체 구간 바로 선택 (TMAP 키 필요)**: 경로선의 빨간 구간에 마우스를 올리면 굵어지고, 클릭(폰은 탭)하면 회피 구간으로 추가됩니다. 하단 목록의 "정체 2.1km · 영동고속도로" 버튼을 눌러도 됩니다.
   - **직접 지정**: 경로 위에서 정체 직전 나들목을 **A**, 정체가 끝나는 나들목을 **B**로 탭합니다. 지금은 안 막혀도 평소 막히는 구간을 미리 피해볼 때 씁니다.
3. 도로 조건을 고릅니다.
   - **좁은 길·농로·골목 피하기** (기본 켜짐)
   - **고속도로·국도 위주 (신호 적은 길)** (선택)
   - **어린이 보호구역 피하기** (선택)
4. 결과에서 **+5/+10/+15/+20분** 버튼으로 허용 범위를 고릅니다.
5. 추천 경로를 확인하고 **네이버 지도로 안내 시작** → **네이버 지도 열기**.
6. 우회로도 막혀 있으면 **구간 추가**로 더 찍으면 됩니다.

## 동작 방식

- **A까지는 지금 경로 그대로** 갑니다. A보다 1.5km 앞 지점에서 갈라지도록 계산하고, 출구가 멀어서 못 나가면 5km, 12km 앞으로 물러나서 다시 시도합니다.
- A~B 사이 고속도로 본선은 약 900m마다 작은 차단 박스(약 140m)로 끊어서 지나가지 못하게 합니다.
- 갈라진 지점부터 세 가지를 비교합니다.
  - **최적 우회**: 엔진이 고른 가장 빠른 길 (재진입 여부도 엔진이 판단)
  - **B 지나서 바로 재진입**: B 바로 뒤에서 같은 고속도로로 복귀
  - **고속도로 없이 끝까지**: 고속도로를 나온 뒤 재진입하지 않음
- **좁은 길·농로·골목 피하기**: 경로 계산 결과의 도로 종류 정보(동네길, 농로·임도, 비포장, 오솔길)를 보고, 우회로에 그런 구간이 있으면 그곳을 막고 다시 계산합니다(최대 3번). 출발 후 400m와 도착 전 1.5km는 진입로라 예외입니다. 남은 좁은 길 거리는 카드에 표시됩니다.
- **고속도로·국도 위주**: 경로 계산 결과의 도로 등급에서 1등급(고속도로·자동차전용도로·주요 국도 = motorway/trunk/primary)을 우선합니다. 2등급(지방도·군도급 = secondary/tertiary/unclassified)이 1km 이상 이어지면 그 구간을 막고 다시 계산합니다. 우회 부분의 신호등을 OpenStreetMap에서 한 번 조회해 교차로 단위로 세고(카드에 "신호등 약 N개"), 추천 순위에 신호등 1개당 약 25초(실시간 시간일 때는 10초)를 더해 신호가 적은 길을 우선합니다.
- **어린이 보호구역 피하기**: 우회로 120m 안의 초등학교·특수학교·유치원·어린이집을 OpenStreetMap(Overpass, 키 불필요)에서 찾아 그 주변을 막고 다시 계산합니다. 출발지·목적지 1km 안은 예외입니다. 실제 보호구역 지정 범위가 아니라 학교 위치 기준의 근사치입니다.
- 각 경로가 A보다 몇 km 앞 출구로 나가는지, B 뒤에서 재진입하는지 표시합니다. 같은 경로가 나오면 하나로 합칩니다.
- TMAP 키가 있으면 각 우회 경로를 네이버에 넘길 경유지 그대로 TMAP에 다시 물어봐서, 실시간 예상 시간과 정체 색상을 받습니다. 그 길이 회피 구간을 일부라도 지나면 "회피 구간 일부 통과"로 표시합니다.
- 지금 경로(실시간, TMAP 없으면 정체 없는 기준)와 비교해 추가 시간을 계산하고, 허용 범위 안에서 시간 순(3분 이내 차이는 거리 짧은 순)으로 추천합니다.
- 네이버로 넘길 때 첫 경유지는 고속도로를 나온 직후에 둡니다. 그래서 네이버 지도도 같은 출구로 나가게 됩니다. A가 지금 경로 위에 없으면 출발지부터 전체를 다시 계산합니다.

## 알아둘 점

- TMAP 키가 없으면 추가 시간은 정체가 없을 때 기준(OSM 데이터)입니다. 실제 정체를 지나는 것보다 보수적으로 잡히고, 국도는 신호 대기가 덜 반영되어 조금 짧게 나올 수 있습니다.
- TMAP의 정체 정보는 네이버와 출처가 달라서 색이 조금 다를 수 있습니다.
- 차단 박스가 고속도로 아래를 지나는 국도와 겹치면 그 국도도 막힐 수 있습니다. 결과가 이상하면 구간을 조금 다르게 찍어보세요.
- 지도·경로 계산은 인터넷이 필요합니다. 앱 화면 자체는 폰에 캐시됩니다.
- 네이버 지도로 넘기기는 네이버 지도 앱이 설치된 폰에서만 동작합니다.
- 좁은 길 판단은 OpenStreetMap의 도로 분류를 따릅니다. 지도에 분류가 잘못 들어간 길은 걸러지지 않을 수 있으니, 처음 가는 우회로는 지도에서 한 번 확인하세요.
- 호출 절약: 장소 검색은 검색 버튼(엔터)을 누를 때만, 같은 출발지·목적지의 지금 경로는 5분간 다시 부르지 않습니다. 우회 후보는 최적 우회가 B 뒤에서 재진입하면 '고속도로 없이'만, 재진입하지 않으면 'B 지나서 재진입'만 추가로 계산합니다(한 번에 2회). 좁은 길 회피 반복은 최대 2번, 보호구역 조회는 1번입니다.
- 일반적인 검색 한 번에 OpenRouteService 2~6회, 조건을 모두 켜도 약 8회 이내입니다.
